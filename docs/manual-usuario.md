# Manual de Usuario

## Cómo empezar
1. Selecciona dificultad (EASY, MEDIUM, HARD).
2. Pulsa “Nuevo”.
3. El tablero se genera automáticamente.

## Cómo jugar
- Haz clic en una casilla vacía.
- Escribe un número del 1 al 9.
- Si fallas, la casilla se pone rosa y aumenta el contador de fallos.
- A los 3 fallos, la partida termina.

## Resolver
Pulsa “Resolver” para ver el tablero completo.

## Objetivo
Completar el Sudoku sin superar los 3 fallos.
